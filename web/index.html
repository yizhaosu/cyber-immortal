现实行为修仙后果
消耗 Token修为 = 60 × √(万 Token) × (1 + 灵根%)。每天烧 80 万 Token、偶尔熬夜的重度用户，大约一周筑基、一个月金丹、三个月元婴、一年渡劫。烧得越多修得越快，但边际递减，空转刷 Token 不划算。缓存命中不计。
熬夜导入时按最后一次 AI 活动时间算。每晚一个时辰：修为 +15%，夜修值 +10，道心 −5。23 点前睡：道心 +8。
对话轮数每 50 轮灵根 +1，每 20 轮神识 +1k。
被幻觉坑每次幻觉抗性 +2，道心 −3。吃一堑长一智。
道心低于 25心魔缠身，修为折半。解药是早睡，或者一颗清心丹。
修为圆满每个境界分九层。修为圆满且满足这一关的道行要求（修行天数、道心、法宝、早睡等）才能渡劫，每天只能渡一次。溢出的修为存进灵气储备，渡劫成功后灌入新境界。天雷数随境界增加，道心越高安全区越宽。失败损失四成修为。
每天打开游戏晨课上香求签：灵石 +10 起，连签越久越多，每满 7 日得一件法宝。签文决定今日首次修行的修为倍率。每天还有三门晨课，全部完成开宝箱。
离开电脑开始闭关后，每小时约得 3% 天的修为和 1 点道心，最多累积 8 小时，回来收功。

八大境界

炼气 Prompt 童子 → 筑基 上下文修士 → 金丹 Token 结丹 → 元婴 Agent 元婴 → 化神 多模态化神 → 渡劫 对齐天劫 → 大乘 千卡大乘 → 飞升 奇点。洞府里的服务器塔会随境界长高。

法门

剑修修为 ×1.1；文修养道心；丹青修更容易出法宝；符箓修修为 ×1.25 但伤道心；散修佛系，修为 ×0.8。

法宝

剑类加修为，书类养道心，画类增掉落，符类产灵石，壶类压夜修值，塔类护渡劫。品阶越高效果越强，佩戴才生效。

丹房

每天三次炉火。聚气丹给修为，清心丹回道心，安神丹压夜修值，护心丹让下次渡劫多一层金光，洗髓丹长灵根。

数字资产

法相随境界长出光环，熬夜多了会变成夜修魔相。每次渡劫成功必得一件灵品以上法宝，日常打卡有概率掉落。

排行榜

榜上只按真实灵契里的 Token 和熬夜计算，不受天象、丹药、法宝影响，所以游戏里怎么玩都不会影响公平。
